Privacy Policy

Effective November 2, 2026

The short version: Aktobly does not collect, store, sell or share any personal data. What you write is processed by an AI model on your own computer and goes nowhere else. Neither the app nor this website uses accounts, cookies, analytics or trackers.

1. The Aktobly app

Your writing. Text you type or paste into Aktobly is sent only to the Ollama server set in Aktobly's Settings. By default that is http://127.0.0.1:11434, which is your own computer. The text is used to generate the response and is not saved by Aktobly.

Remote servers. If you change the Ollama address to another machine (for example a server on your network), your text will be sent to that machine. Aktobly shows a warning when you do this. That server's operator, not Aktobly, controls what happens to the data there.

Settings. Aktobly saves your preferences (such as language, tone, shortcut and Ollama address) in a settings file on your computer at %APPDATA%\com.aktobly.app\settings.json. This file never leaves your device.

What Aktobly never does:

  • No accounts, sign-ups, email addresses or licence keys.
  • No analytics, telemetry, usage statistics or crash reports.
  • No writing history or chat logs.
  • No global keystroke recording. Aktobly listens only for its own shortcut, which Windows reports to it, and reads only what you type into its window.
  • No reading of other applications, files, screens or your clipboard. Aktobly only writes to the clipboard when you click Copy.
  • No automatic update checks or other background network requests.

2. Third-party software you install

Aktobly relies on Ollama and Meta Llama models, which you install separately. When you download Ollama or pull a model, those downloads are governed by the providers' own terms and privacy policies. Once installed, the model runs locally.

3. This website

This website is a set of static pages. It sets no cookies, runs no analytics or advertising scripts, and loads no fonts, scripts or images from third parties. Like any web server, our hosting provider may keep standard technical logs (such as IP address and requested page) for security and operations, under its own policies.

4. Children

Aktobly collects no personal data from anyone, including children.

5. Open source

Aktobly is open source under the MIT License, so anyone can check these statements against the source code.

6. Changes

If this policy changes, the updated version will be posted on this page with a new effective date. Any change that would collect data would be called out prominently and would need your opt-in.

7. Contact

Questions about privacy? Open an issue in the project's public source repository.
